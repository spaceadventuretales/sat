# Courier Data And Physical Message Transport

Not all information travels best as a signal.

Some data is too large, too sensitive, too heavily encrypted, too politically dangerous, or too legally restricted to trust to ordinary networks. In those cases, civilization still uses ships, vaults, and certified couriers.

## Why Couriers Still Exist

- physical transport can be harder to intercept or forge
- some archives are too large for routine beam transfer
- some secrets are moved only by high-trust human or bounded-AI custodians
- frontier regions may have poor network infrastructure

## Narrative Value

This preserves one of the oldest story truths: sometimes a message still has to be carried physically, and that makes the carrier important.
