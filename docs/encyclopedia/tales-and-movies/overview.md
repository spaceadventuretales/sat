# Tales and Movies

Stories and movies now have dedicated top-level sections in the site.

- Stories hub: /stories
- Movies section: /movies

This page remains as a continuity bridge inside the encyclopedia for legacy links.

## Story layers

- Tales: short and medium-form narrative arcs
- Sagas: multi-episode long arcs
- Movies: script, production, and release planning

## Production guidance

- Anchor all stories to the canonical timeline.
- Link every tale and movie to relevant characters, worlds, and events.
- Record canon changes with rationale when story needs evolve.

## Starter pipeline

1. Concept and premise
2. Canon fit check
3. Outline and characters
4. Draft script or tale
5. Continuity review
6. Publish
